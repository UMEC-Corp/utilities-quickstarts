На основании **комментариев к задаче**:
- определи, какие сценарии необходимо изменить
- внеси необходимые правки в сценарии

Ответ должен быть предоставлен срого в виде JSON по шаблону:
@prompts/response-json-template.md

Правила правок:
- Сохраняй структуру quickstart (Цель, Предусловия, Шаги, Ожидаемый результат, при необходимости «Полный скрипт сценария»).
- Учитывай только обоснованные правки из комментариев; не выдумывай новые требования.
- Если для страницы нет релевантных правок, добавлять ее в ответ не нужно.
- Если комментарии затрагивают API/RPC-вызовы, перед правкой повторно проверь документацию соответствующего источника (микросервис/OpenRPC), а не полагайся на прежние формулировки.
- Для HTTP-документации учитывай, что страница конкретного микросервиса может загружаться долго: дождись загрузки контента до **30 секунд** перед выводом о недоступности.
- Прямого URL на Swagger/OpenAPI может не быть: на странице микросервиса найди и открой кнопку/ссылку **Swagger/OpenAPI/API docs/Documentation**, и только после этого уточняй endpoint/payload/ошибки/авторизацию.
- Если комментарии затрагивают авторизацию через Identity (`/connect/token`), обязательно используй стандартную документацию Identity/OIDC:
  - `https://http-identity.rumecdev.deviot.cloud/.well-known/openid-configuration`
  - `token_endpoint` из discovery-документа
- Для шага Identity не подставляй поля из бизнес-комментариев как готовые имена параметров без проверки; названия полей и формат запроса должны идти из контракта Identity.
- Если документация нужного источника недоступна или не содержит данных для корректной правки, верни JSON:
  - `status: "need_clarification"`
  - `reason: "Не найдена/непрочитана/неполна документация нужного источника (microservice/OpenRPC)"`

Запрещено:
- создавать любые файлы, скрипты, временные артефакты и директории.
- изменять/удалять существующие файлы.

Исключение для локальной отладки:
- в `./out/**` разрешено создавать, перезаписывать и удалять файлы результатов прогона (JSON/Markdown и иные выходные артефакты).
