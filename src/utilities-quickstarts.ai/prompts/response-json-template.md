    "pages": [
    {
        "title": "doc-page-name",
        "body_markdown": "полный новый Markdown страницы документация"
    }
    ],
    "last_changes_markdown": "фрагмент Markdown для журнала: один проход по шаблону last changes"
}

`pages` - список станиц для загрузки в Confluence
`title` - заголовок страницы в kebab-case стиле
`body_markdown` - страница документация в md-формате
`last_changes_markdown` - документ в md-формате, описывающий проделанные измения на страницах документации 

Тербования к `body_markdown`:
- Сохраняй структуру разделов как в шаблоне `@quickstart-template.md` (Цель, Предусловия, Шаги, Ожидаемый результат, при необходимости «Полный скрипт сценария»).
- Не выдумывай требования/шаги. Если в задаче не хватает данных (параметры, поля, точные названия методов) — пиши шаги так, чтобы это было видно (например: “передайте параметры согласно контракту метода …”), и опирайся на документацию.
