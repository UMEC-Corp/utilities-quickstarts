Возвращай **строго один** из двух JSON-форматов ниже (без текста до/после JSON).

Вариант 1: успешная генерация/правка страниц
```json
{
  "pages": [
    {
      "title": "doc-page-name",
      "body_markdown": "полный новый Markdown страницы документации"
    }
  ],
  "last_changes_markdown": "фрагмент Markdown для журнала: один проход по шаблону last changes"
}
```

Вариант 2: недостаточно подтвержденных данных для корректного сценария
```json
{
  "status": "need_clarification",
  "reason": "Не найдена/непрочитана/неполна документация нужного источника (microservice/OpenRPC)"
}
```

Пояснения для варианта 1:
- `pages` - список страниц для загрузки в Confluence.
- `title` - заголовок страницы в kebab-case стиле.
- `body_markdown` - страница документации в md-формате.
- `last_changes_markdown` - документ в md-формате с описанием изменений.

Требования к `body_markdown`:
- Сохраняй структуру разделов как в шаблоне `@quickstart-template.md` (Цель, Предусловия, Шаги, Ожидаемый результат, при необходимости «Полный скрипт сценария»).
- Не выдумывай требования/шаги. Если в задаче не хватает данных (параметры, поля, точные названия методов), явно указывай это и опирайся только на подтвержденную документацию.
