Сгенерируй quickstart-сценарии **строго по описанию в задаче Jira**.

Ответ должен быть предоставлен срого в виде JSON по шаблону:
@prompts/response-json-template.md

Источники документации (не добавлять в Markdown):
- Публичное API: `https://api.rumecdev.deviot.cloud` (для конкретного микросервиса перейди по ссылке в нём).
- Вебсокеты: endpoint `https://ws.rumecdev.deviot.cloud/ws`.
- OpenRPC (вебсокеты): `https://ws.rumecdev.deviot.cloud/openrpc.json`.

Кодировка и JSON:
- Весь текст сценария и поле `body_markdown` в ответе — **UTF-8**; кириллица и символы в коде должны отображаться корректно.

Запрещено:
- создавать любые файлы, скрипты, временные артефакты и директории.
- изменять/удалять существующие файлы
