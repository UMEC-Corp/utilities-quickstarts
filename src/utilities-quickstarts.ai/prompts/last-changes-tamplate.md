## Таблица изменений

Удобный обзор без полного diff (в Confluence нативный «как в Git» для произвольного текста обычно недоступен; при необходимости детали — в Jira-комментарии или в истории версий страницы).

| Сценарий | Тип | Что изменилось | Где смотреть |
|----------|-----|----------------|--------------|
| `<название>` | правка / новый / удалён / уточнение | Кратко: разделы, шаги, код, предусловия | [страница](url) |
| … | … | … | … |

**Тип** — одно слово из: `новый`, `правка`, `удалён`, `уточнение`, `структура` (перестановка блоков без смысловых правок).

## Фрагменты «было → стало» (опционально)

